# Fundamentals of Data Science — Case Studies 3 and 6

This repository contains two Fundamentals of Data Science case studies.

## Case Study 3: Titanic Survival Prediction
- Dataset: Titanic passenger dataset
- Algorithm: Logistic Regression
- Includes exploratory data analysis, preprocessing, model evaluation, coefficient interpretation, and a Streamlit application.

## Case Study 6: Bank Marketing Prediction
- Dataset: Bank Marketing dataset
- Algorithms: Logistic Regression, Decision Tree, K-Nearest Neighbours (KNN), and Random Forest
- Includes exploratory data analysis, model comparison, confusion matrices, ROC curves, and business recommendations.

## Repository Structure
- `Case_Study_3_Titanic/` — Titanic analysis and Streamlit application.
- `Case_Study_6_Bank_Marketing/` — Bank Marketing analysis and model comparison.

Each folder contains the relevant project files and report.
